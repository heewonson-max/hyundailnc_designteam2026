# Secret Manitto

우리 팀 크리스마스 마니또 사이트입니다. GitHub Pages로 띄우고, 로그인과 저장은 Firebase(무료 Spark 요금제)를 씁니다.

```
index.html          사이트 전체 (디자인과 기능)
firebase-config.js  Firebase 연결 값과 관리자 이메일
firestore.rules     데이터 보호 규칙 (Firebase 콘솔에 붙여 넣기)
```

`firebase-config.js`를 비워 두면 예시 참가자로 동작하는 미리보기 모드로 열립니다. 예시 계정은 김하린 / test1234이고, 새로고침하면 데이터가 사라집니다.

---

## 1. Firebase 프로젝트 만들기 (약 10분)

1. https://console.firebase.google.com 에서 **프로젝트 추가**를 누릅니다. Google 애널리틱스는 꺼도 됩니다.
2. **빌드 > Firestore Database > 데이터베이스 만들기**
   - 위치는 `asia-northeast3 (서울)`을 고릅니다.
   - "프로덕션 모드로 시작"을 고릅니다.
3. **빌드 > Authentication > 시작하기 > 로그인 방법** 탭에서 두 가지를 켭니다.
   - **익명**: 참가자의 브라우저가 저장 서버에 접속할 때 씁니다. 참가자 로그인(이름+비밀번호)은 사이트가 따로 처리합니다.
   - **이메일/비밀번호**: 관리자 로그인용입니다.
4. **Authentication > 사용자 > 사용자 추가**에서 관리자 이메일과 비밀번호를 만듭니다.
5. **Authentication > 설정 > 승인된 도메인**에 `내아이디.github.io`를 추가합니다.
6. **프로젝트 설정(톱니바퀴) > 일반 > 내 앱 > 웹(`</>`)**으로 앱을 등록합니다. 화면에 나오는 `firebaseConfig` 값을 `firebase-config.js`에 붙여 넣고, `adminEmails`에 4번에서 만든 관리자 이메일을 적습니다.
7. **Firestore Database > 규칙** 탭에 `firestore.rules` 내용을 전부 붙여 넣습니다. 파일 안의 `admin@example.com`을 관리자 이메일로 바꾼 뒤 **게시**를 누릅니다.

## 2. GitHub Pages로 배포 (약 5분)

1. GitHub에서 새 저장소를 만듭니다 (예: `secret-manitto`, Public).
2. 이 폴더의 파일 4개를 올립니다. 웹에서는 **Add file > Upload files**로 올릴 수 있습니다.
3. 저장소 **Settings > Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 정하고 저장합니다.
4. 1–2분 뒤 `https://내아이디.github.io/secret-manitto/` 주소로 열립니다.

나중에 내용을 고치면 같은 파일을 다시 올리면 됩니다. 커밋하면 Pages가 자동으로 다시 배포합니다.

## 3. 운영 순서

1. 팀원에게 주소를 공유합니다. 각자 **참가 신청** 탭에서 이름, 좋아하는 것, 싫어하는 것, 한마디, 비밀번호를 적습니다.
2. 관리자는 `주소/#admin`으로 들어가 관리자 이메일로 로그인합니다. 일정(미션 시작일, 최종 공개 일시)을 저장하고 **마니또 배정하기**를 누릅니다.
3. 참가자는 이름+비밀번호로 로그인해서 봉투를 열고, 매주 미션 3개를 하고, 받은 선물을 등록하고 답장합니다. 마니또 맞추기는 공개 1시간 전까지 3번 바꿀 수 있습니다.
4. 공개 시각이 지나면 **공개** 화면에서 모든 짝, 순위, 시상이 나옵니다. 각자 한 번씩 접속해야 그 사람의 카드가 채워집니다.

## 데이터는 이렇게 저장됩니다

| 무엇 | 어디에 | 누가 볼 수 있나 |
|---|---|---|
| 비밀번호 | 저장하지 않음 (비밀번호로 만든 키로 개인 열쇠를 잠가 둠) | 아무도 |
| 신청서 내용 | `entries` | 화면에는 나를 챙길 마니또에게만 표시 |
| 마니또 배정 | `assign` (사람마다 암호화) | 본인만 열 수 있음. 관리자도 볼 수 없음 |
| 미션 체크, 내 글 목록, 닉네임 | `pstate` (본인 비밀번호로 암호화) | 본인만 |
| 게시글, 댓글, 좋아요 | `posts`, `comments`, `likes` | 모두 (작성자 이름 없음) |
| 받은 선물과 답장 | `receipts` | 화면에는 본인과 준 사람에게만 표시 |
| 점수, 맞추기 선택 | `scores`, `guesses` | 화면에는 최종 공개 때만 표시 |

## 알아 두실 점

- 비밀번호는 되찾을 수 없습니다. 잊은 사람은 관리 화면에서 신청서를 지우고 다시 신청하면 됩니다. 배정 뒤라면 다시 배정해야 합니다.
- 점수는 각자 브라우저에서 계산해 저장합니다. 개발자 도구를 다룰 줄 아는 사람은 조작할 수 있으니, 상금이 걸린다면 감안해 주세요.
- 무료 요금제 한도(하루 읽기 5만 회, 쓰기 2만 회)는 팀 단위 이벤트에 충분합니다.
